# .github

Organization profile and default community health files for [RackMoon](https://github.com/rackmoon).

| Path | Purpose |
| --- | --- |
| `profile/README.md` | The page shown at [github.com/rackmoon](https://github.com/rackmoon) |
| `CONTRIBUTING.md` | Default contributing guide |
| `SECURITY.md` | How to report vulnerabilities |
| `.github/ISSUE_TEMPLATE/` | Default issue forms |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request template |

These files apply to every public repository in the organization that does not have its own version.
